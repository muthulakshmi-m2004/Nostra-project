# Nostra-clone 👕🛍️

A modern e-commerce web application inspired by the Nostra fashion platform.
This project focuses on creating a clean UI, smooth user experience, and responsive design for online clothing shopping.

---

## 🚀 Features

* 🧭 Responsive navigation bar
* 🛒 Product listing and shopping layout
* 🔍 Search and filter functionality
* ❤️ Wishlist / favorites UI
* 📱 Fully responsive design (mobile + desktop)
* 🎨 Modern and minimal user interface

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Styling:** Flexbox / Grid / Responsive design
* **Version Control:** Git & GitHub

---



## 🎯 Learning Goals

This project was built to:

* Practice frontend development skills
* Improve UI/UX design understanding
* Learn responsive layouts
* Understand basic e-commerce flow
